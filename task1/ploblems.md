##  Проблемы
1. Данные в DWH лежат не органзованно. Это мешает эффективному поиску и обработке данных по определенному бизнес направлению
2. Также следствием первого пункта является долгое внедрение новой функциональности
3. Нет разграничения доступа к данным. Операторы могут извлекать любые данные
4. Возможно следует обновить шину интеграци на kafka

# MoSCoW

## Must
Данные в DWH лежат не органзованно. Чтобы создать портал самообслуживания в первую очередь надо будет разделить данные по доменам, соотвественно правильно организовать их в DWH

## Should
Раграничение доступа пользователей. Важно чтобы потребители данных имели доступ только у тем данным к которым им предоставлен доступ.
## Could
Обновить шину данных на Kafka
